# docker-images

## Использование
1. Создать каталог по имени будущего образа
2. Добавить Dockerfile + файлы для билда при необходимости
3. Пайплайн можно запустить вручную из веб интерфейса. Автоматически создается при условиях:
  - наличие измененных файлов
  - ветка main либо открыт MR в main  
  - наличие git тэга (образ создается с тэгом = git tag)
